# Cirrus v2 Codex — v1 최소 버그 수정안

`cirrus_v2_codex.js`는 `cirrus_v1.js`를 다시 복사한 뒤 확인된 버그에 대한 조건 검사와 타이머 정리만 추가한 파일입니다. 기존 `appRunning`, `zombieRestartInProgress`, 워치독과 START/STOP 스크립트 호출 구조를 유지합니다.

## 적용한 수정

1. **SFU 제외:** 앱 수명주기의 사용자 수와 스트리머 수에서 SFU를 제외합니다. `players`/`streamers` 맵과 기존 `playerCount` 메시지는 유지합니다. 종료 중인 연결은 기존처럼 close 이벤트까지 맵에 남습니다.
2. **offer 타이머:** 구독 해제·서버 측 연결 해제 시 취소하고, 만료 시 플레이어 및 스트리머 객체·구독·소켓 상태를 확인합니다. 명령이 진행 중이면 같은 20초 감시를 다시 예약합니다.
3. **명령 중복 방지:** 기존 다섯 exec 호출을 작은 `runAppCommand()` 함수로 감쌉니다. 실행 중인 START/STOP은 겹치지 않으며, 필요한 반대 작업은 현재 콜백이 끝난 뒤 실행합니다. 새 상태 머신은 추가하지 않습니다.
4. **종료 재시도:** 새 사용자 접속 시 조기 반환보다 먼저 취소하고, 재시도 직전에도 사용자 수를 확인합니다. 명령 실행 중인 회차는 재시도 횟수를 소진하지 않고 건너뜁니다.
5. **기동 감시:** 모든 START 경로에서 기존 기동 시각과 워치독을 설정합니다. 실패 후 appRunning=false가 되어도 대기 사용자가 있으면 기존 90초/30초 감시로 재시도합니다. 좀비 재시작 실패의 즉시 반복 호출은 이 감시로 통일합니다.
6. **등록·구독:** 같은 소켓의 같은 endpointId와 같은 대상의 subscribe는 중복 처리하지 않습니다. 대상 변경 시 기존 구독을 해제합니다. 늦은 launcher 오류가 이미 열린 UE 연결을 실행 중 아님으로 되돌리지 않도록 합니다.
7. **메시지 예외:** null/배열/원시값을 기존 JSON 오류 경로로 거부하고, 기존 핸들러의 동기·비동기 예외를 해당 연결에서 처리합니다. SDP/ICE 필드 스키마나 크기 제한은 새로 추가하지 않습니다.

## 그대로 둔 동작

- mDNS(.local) 주소 치환, HTTPS/CA 처리, 인증서 안내 HTML, 공통 설정·로그 모듈
- START/STOP 명령 문자열, Windows RunDir, Linux 스크립트 경로
- 유휴 10분, offer 20초, 기동 감시 90초, ping 제한 60초, 워치독 주기 30초
- 종료 재시도 간격 15초와 최대 4회
- 기존 WebSocket 종료 코드와 close 핸드셰이크, 브라우저 우선 offer 전달
- 기존 메시지 종류·전달 경로, npm 실행 명령, package.json과 의존성

대규모 상태 관리, 지수 백오프·쿨다운, exec 제한 시간, TLS 체인 합치기, mDNS 기본값 변경, 강제 소켓 종료, 전역 프로세스 종료 핸들러는 포함하지 않습니다.

## 실행 및 검증

SignallingWebServer 폴더에서 기존과 같은 Node 환경을 사용합니다.

```powershell
node --check ./cirrus_v2_codex.js
node --test ./tests/cirrus_v2_codex.test.js
node ./cirrus_v2_codex.js --configFile ./config.json
```

테스트는 전체 진입점을 실행하지만 소켓·타이머·기동 명령·설정 접근을 메모리 어댑터로 대체합니다. 실제 서버나 UE는 기동하지 않습니다. v1과 설정/TLS/HTTP 안내/mDNS 코드 및 시간 상수의 동일성도 검사합니다.

실제 BAT/sh·UE·브라우저·TURN·인증서 통합 검증은 하지 않았습니다. 명령 잠금은 셸 콜백이 완료될 때 해제되며, 기존처럼 별도 명령 타임아웃은 없습니다. 스크립트가 반환하지 않으면 잠금이 유지됩니다. PID 소유권, 실제 UE 종료 확인과 외부 감시기의 동작은 스크립트 검토가 필요합니다.

이 파일은 별도 진입점입니다. 기존 cirrus.js/cirrus_v1.js와 실행 설정은 변경하지 않습니다.
